## Run Locally

```bash
git clone https://github.com/GoundPrincek/Portfolio.git
cd Portfolio
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

### Backend

Open another terminal:

```bash
cd backend
npm install
npm run dev
```

> Configure the required environment variables before starting the backend.
