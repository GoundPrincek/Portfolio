## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/GoundPrincek/Portfolio.git
cd Portfolio
```

### 2. Start Frontend

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

### 3. Start Backend

Open another terminal:

```bash
cd backend
npm install
npm run dev
```

> Backend environment variables may be required depending on the current implementation.
